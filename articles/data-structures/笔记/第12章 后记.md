# 第十二章 后记

## 1.后记

- 本教程自 6 月动笔到年末收尾，配合基本习题与资料搜索，读者应已掌握数据结构的基本盘。
- 核心判断：数据结构是“编程 + 硬件 + 数学”三者的结合体，是计算机与数学学习者都必须跨过的门槛——跨过它，才算真正入门。
- **方向一：算法竞赛**
  - 大学生主流赛事：ACM 与蓝桥杯；
  - ACM 含金量更高、更难，要求编程能力 + 算法思维 + 数学 + 英语（题面全英文），错一个点即 0 分；
  - 蓝桥杯相对容易，允许按测试点得分甚至暴力得分；
  - 此外大量企业与高校会组织培训式训练或比赛。
- 算法训练的真实体验：不像开发那样线性增长，可能耗费大量心血却颗粒无收，一旦突破又欣喜若狂，需要十二分的努力。
- **方向二：机器学习 / 深度学习（AI）**
  - 标准算法方向，也是高校研究主流；
  - 很看重学历与学校背景，需要扎实数学功底与思辨能力；
  - 可通过 Kaggle 等数据竞赛练手，长期看要多发研究型论文。
- **方向三：前端 / 后端开发**
  - 记忆性内容更多，后端还要求一定的思维辨析能力；
  - 需要项目经验积累：从音乐播放器、视频播放器、小游戏，到 Web 商城、微信小程序、安卓应用；
  - 比喻：开发像盖大楼，各工种分工协作，“盖完高楼却没装电梯”就是典型的协作失败。
- **其他方向**：运维、测试、架构等，也都以计算机基础为前提，数据结构正是打底的那块基石。
- 现实例证：Java 岗面试常问“HashMap 底层怎么实现”——日常开发直接拿来用，但面试与底层理解都绕不开数据结构。
- 作者自述：本篇写了近 3 周，反复删改，只为在结尾以聊天的方式交代学习方向，并表达对读者的感谢与祝福（署名：UDP广播协议叫吃饭 / 木十）。

## 2.参考及相关链接

- **参考书目与来源**：
  - 《大话数据结构》程杰 著；
  - 《数据结构与算法》小黑书（C 语言版）；
  - 《算法与数据结构》小黑书（JAVA 版）；
  - 搜索引擎（百度、谷歌）、CSDN、Stack 论坛。
- **学完本教程应达到的八项能力**：
  - 能自由写出链表及基本操作与进阶（如排序）；
  - 熟练使用栈和队列，并用于算法设计；
  - 熟练创建树，能读懂陌生的树形结构；
  - 具备设计有特定功能二叉树（如 BST、哈夫曼树）的思路；
  - 基本掌握图论经典算法（最小生成树、最短路、遍历）；
  - 会根据场景选择图的搜索方式（DFS / BFS）；
  - 掌握 DFS、BFS 等基本搜索算法；
  - 了解八皇后等经典例题的解法套路。
- **推荐过关习题（有难度，需耐心）**：
  - 1438 大臣的旅费：DFS + 树的直径；
  - 1437 城市建设：并查集 + 最小生成树；
  - 1642 暗恋：简单 DP，也可暴力或 BFS；
  - 1548 盾神与砝码称重：DFS 或 DP；
  - 1732 连通图：并查集；
  - 1436 地宫取宝：记忆化搜索；
  - 1627 拦截导弹：最长（不上升）子序列；
  - 1672 迷宫问题：BFS；
  - 1426 九宫重排：BFS + 哈希（状态判重）；
  - 1427 买不到的数目：数论找规律；
  - 1445 最大子阵：DP 或前缀和 + 最大子序列；
  - 1743 大数排序：排序 + 高精度；
  - 1108 守望者的逃离：DP。
- 使用建议：每章学完先做对应基础题，再按上表挑 1~2 道综合题，能把“数据结构 + 算法 + 数学建模”串起来才算真掌握。
