# 第十一章 算法和竞赛

## 1.哈希算法实例详解

- **Hash（散列 / 杂凑）**：把任意长度的输入（预映射 pre-image）经散列算法变换成**固定长度的输出**（散列值），本质是以空间换时间。
- 直观理解：学号 `190020117`（年级+学院+班级+序号）可直接压缩成 `192117` 这样的短地址，查到地址即拿到数据，避免 O(n) 逐一遍历。
- **设计哈希函数需考虑五件事**：
  - 计算散列地址的时间（函数不能太复杂）；
  - 关键字的长度；
  - 表长（不宜过长或过短，避免浪费内存或算力）；
  - 关键字分布是否均匀、有无规律；
  - 在满足上述条件下尽量减少冲突。
- **哈希表**：经哈希函数转换后得到的表，核心难点是**冲突处理**——不同数据可能映射到同一地址。
- **冲突处理方法**：+1 法（地址加 1 顺延）、开放定址法、链地址法、公共溢出法、再散列法、质数法等，需按数据特征选择。
- 哈希是一种“思想”而非单一算法：既能提升查询效率，也用于数字签名等安全场景。
- **示例：O(1) 判断 1000 以内质数**
  - 先用 `is_pri()` 逐个数试除建表（建表并非 O(1)）；
  - 是质数就把 `arr[i] = 1`；
  - 之后每次查询只看 `arr[input]`，O(1) 出结果。
- 注意：这种“打表”做法浪费空间，只作思维演示；实际可用筛法或更省空间的表示。
- 记忆点：哈希 = 用一次函数计算替代多次比较；代价是空间与冲突处理。

## 2.动态规划DP算法详解

- **来源**：运筹学分支，20 世纪 50 年代由 R.E.Bellman 等人提出**最优化原理**，把多阶段决策过程转化为一系列单阶段问题逐段求解。
- **基本思想**：若原问题最优解可由子问题最优解推导，就先求子问题；子问题重复出现时，就自底向上逐步构造，避免重复计算。
- **最直观的例子**：斐波那契 `a[i] = a[i-1] + a[i-2]`
  - 自底向上（从 1 递增填表）比自顶向下递归快得多；
  - 因为递归 `f(n-1)+f(n-2)` 会大量重复计算（算 f(5) 时又算了一遍 f(4)）。
- **四个特点**：
  - 原问题划分为一系列子问题；
  - 每个子问题只求一次，结果存入表中，用时直接查，不重复计算；
  - 自底向上计算；
  - 整体最优解由子问题最优解经**状态转移方程**得到（子问题即“状态”）。
- **四大类别（可按序学习）**：线性动规、区域动规、树形动规、背包动规。
- **学习方法**：
  - 必须勤记笔记；
  - 从具体题（如最长不下降子序列）入手：把“选 / 不选”画成二叉树，穷举所有状态；
  - 从树中提炼出状态转移方程，再据方程写代码；
  - 同类题练到一定量自然熟练。
- 记忆点：DP 的三件套永远是——**状态定义、状态转移方程、边界与初值**。

## 3.贪心算法实例详解

- **定义**：每一步都做出“当前看来最好”的选择，不从整体最优上考虑，得到的是**局部最优解**。
- **关键前提：无后效性**——某状态以前的过程不影响以后的状态，只与当前状态有关；否则贪心不成立。
- **基本思路**：从初始解出发一步步推进，每一步只考虑一个数据，选择满足局部优化的方案，直至枚举完所有数据。
- **四步建模**：
  - 建立数学模型描述问题；
  - 把问题分成若干子问题；
  - 对每个子问题求局部最优解；
  - 把局部最优解合成原问题的解。
- **与 DP 的区别**：贪心求局部最优（可能不是全局最优）；DP 求全局最优。有趣的对照是——01 背包本质是 DP 的选择问题，而部分背包（可分割）才能用贪心。
- **学习方法**：先把 01 背包、部分背包弄熟，再练装箱、切割、区域分配类题；很多时候你已经在用贪心而不自知。
- **经典应用**：霍夫曼编码、Prim / Kruskal 最小生成树、Dijkstra 单源最短路，甚至一些暴力搜索题里也藏着贪心思维。
- 检验要点：写完先自问“这个局部选择会不会让后面变差”，能举出反例说明策略有问题。

## 4.博弈算法实例详解

- **博弈论（Game Theory / 对策论）**：现代数学分支，也是运筹学重要学科，研究竞争性现象中的预测行为与优化策略。
- 通俗说：两方或多方为某个目标进行的竞争（国家交锋、游戏对局、谈加薪都是博弈）。
- **三个特点**（本教程讨论的模型）：
  - 两人轮流决策的**非合作博弈**，双方都采用最优策略；
  - 博弈**有限**：无论怎么决策，有限步内必分胜负；
  - **公平博弈**：双方遵循的规则相同。
- **学习方法**：先熟悉四大经典模型——**巴什博弈、威佐夫博弈、斐波那契博弈、尼姆博弈**，理解模型及其变种，多数题目只是“换汤不换药”。
- 进阶：学习**博弈树**与**决策树**，以及启发式算法，与人工智能的思路接近，难度陡增。
- 入门抓手：巴什博弈（n 个石子每次取 1~m 个，取完者胜）的结论是 `n % (m+1) != 0` 先手必胜；SG 函数是通用工具。
- 练手：题库按“博弈论”标签检索，当前题目偏入门，可自行扩展。
