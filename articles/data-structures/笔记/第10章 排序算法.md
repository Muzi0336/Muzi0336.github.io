# 第十章 排序算法

## 1.冒泡排序算法实例详解

- **核心思想**：相邻两两比较，逆序就交换；每趟把当前范围内的最大值“冒”到末尾，像气泡上浮。
- **一趟的定义**：从第一对比较到最后一对，结束时最大元素落到本趟末尾。
- **复杂度与稳定性**：平均 O(n²)，最坏 O(n²)，最好 O(n)（原本有序），空间 O(1)，**稳定**排序。
- **过程**（以 {70,50,30,20,10,70,40,60} 为例）：第 1 趟后最大值 70 到末尾；第 2 趟次大值再到位……第 4 趟其实已有序，但程序仍会跑到第 7 趟，这是浪费算力。
- **优化**：加 flag，某趟没有发生交换即说明已有序，直接 break（原实现无此优化）。
- **代码要点**：

```cpp
for(int i = 0; i < n; i++)
    for(int j = 0; j < n - i; j++)
        if(a[j] > a[j+1]) swap(a[j], a[j+1]);
```

- 循环上界 `n - i` 的作用是缩小范围，已排好的尾部不再参与比较。
- `swap` 可直接用 std 提供的函数，也可自定义模板版 `template<class T> void swap(T &a, T &b)`。
- 记忆点：冒泡是八大排序中最简单的一种，写法固定，适合入门与教学演示。

## 2.简单选择排序算法实例详解

- **核心思想**：每一趟从未排序区间中挑出最小值（或最大值），与区间首元素交换，逐步扩大有序区。
- **与冒泡的区别**：冒泡是“边比边换”，交换频繁；选择排序是“比完再换一次”，每趟最多交换一次。
- **复杂度与稳定性**：平均/最好/最坏都是 **O(n²)**（比较次数固定，与数据初始顺序无关），空间 O(1)，**不稳定**（交换会打乱相等元素的相对次序）。
- **过程**：第 i 趟在 `[i, n-1]` 中找最小元素下标 min，然后 `swap(a[i], a[min])`。
- **代码要点**：双重循环，外层 i 从 0 到 n-2，内层找 min 下标，内层结束后交换一次。
- 记忆点：交换次数最少（≤ n−1 次），数据元素较大、交换代价高时优于冒泡。

## 3.直接插入排序算法实例详解

- **核心思想**：把待排元素逐个插入到前面“已排好序”的序列中，像打扑克摸牌插牌。
- **过程**：取当前元素 temp = a[i]，从 i−1 往前逐个比较，比 temp 大的元素整体后移一位，直到找到合适位置插入 temp。
- **复杂度**：平均 O(n²)、最坏 O(n²)，**最好 O(n)**（已有序，每次只需一次比较），空间 O(1)，**稳定**。
- **代码要点**：

```cpp
for(int i = 1; i < n; i++){
    int temp = a[i], j;
    for(j = i - 1; j >= 0 && a[j] > temp; j--) a[j+1] = a[j];
    a[j+1] = temp;
}
```

- 优点：稳定、在基本有序的数据上非常快；缺点：数据量大时移动次数多。
- 应用：常作为快速排序小区间（长度很小）时的收尾排序，实践中效率最高。

## 4.希尔排序算法实例详解

- **定位**：插入排序的改进版，也称“缩小增量排序”，属**不稳定**排序。
- **核心思想**：先按较大增量 gap 把序列分成若干子序列分别做插入排序，使数据“大体有序”；再逐步缩小 gap，最后一趟 gap=1 做普通插入排序。
- **为什么有效**：前面几趟让元素大幅跳跃式地靠近目标位置，减少后面插入时的移动量。
- **复杂度**：平均 O(n²)，最好 O(n)，最坏 O(n²)，空间 O(1)，**不稳定**（增量跳跃会打乱相等元素次序）。
- **代码要点**：外层枚举增量 gap（常用 n/2 折半递减，也可用 3k+1 序列），每组内部用插入排序。
- 实践特性：主要操作是**比较**而非交换，小数据量时甚至比快排、堆排更快；数据量大时仍不如快排。

## 5.堆排序算法实例详解

- **什么是堆**：用完全二叉树结构维护的一维数组；分大顶堆（每个结点 ≥ 左右孩子）与小顶堆（每个结点 ≤ 左右孩子）。
- 注意：此处的“堆”与编译器中的堆栈概念无关；优先队列的底层就是堆。
- **基本思想**：把数组视为完全二叉树做“堆化”；大根堆的根是最大值，取出根放到数组末尾，再对剩余部分重新堆化，循环直到取完。
- **堆化的顺序**：先从最后一个非叶结点（下标 len/2−1）自下而上建堆（先子树后根），之后每次取根又自上而下调整。
- **复杂度**：平均 O(n log n)、最坏 O(n log n)、最好 O(n log n)，空间 O(1)，**不稳定**（元素交换跨越较大距离）。
- **实现要点**（数组下标从 0 开始）：
  - 左孩子 `2*i+1`、右孩子 `2*i+2`；
  - `Swap(heap, len)` 交换 heap[0] 与 heap[len-1]（把当前最大值放到末尾）；
  - 主循环 `for(i = n; i > 0; i--){ BuildMaxHeap(a, i); Swap(a, i); }`
- 重要应用：求前 k 大/前 k 小（维护大小为 k 的堆，只处理 k 个，无需全排 n 个）。
- 原文复杂度一栏写作“最坏 O(n²)、最好 O(n)、平均 O(n log n)”，与堆排序的实际结论不符；堆排序三种情况均为 **O(n log n)**。

## 6.归并排序算法实例详解

- **核心思想**：分治——把序列不断二分，直到只剩单个元素（天然有序），再把两个有序子序列**合并**成一个有序序列。
- **合并（merge）过程**：把 `[l, mid]` 与 `[mid+1, r]` 用双指针 i、j 比较，小者先放到临时数组/回写原数组，直到一者用完，再把另一者剩余部分接上。
- **复杂度**：平均/最好/最坏都是 **O(n log n)**，空间 **O(n)**（需要辅助数组），**稳定**（相等时优先取左段元素即可保证）。
- **代码要点**（原文给出的是**自底向上**的非递归写法）：

```cpp
for(int sz = 1; sz <= n; sz += sz)                 // 子区间长度翻倍
    for(int i = 0; i + sz < n; i += sz + sz)
        merge(arr, i, i + sz - 1, min(i + sz + sz - 1, n - 1));
```

- merge 内部先用 `aux[]` 拷贝原区间，再 `i = l, j = mid+1` 双指针回写，注意 `i > mid`、`j > r` 的边界处理。
- 自顶向下的递归写法：`merge_sort(l,mid); merge_sort(mid+1,r); merge(l,mid,r)`，两者复杂度相同。
- 稳定性来源：`if(aux[i] < aux[j])` 取左，相等时取右（原文写法），实际要保证稳定应取左段（`<=` 取左）。
- 原文汇总表把归并空间写作 O(1)，属笔误，正确为 **O(n)**。

## 7.快速排序算法实例详解

- **地位**：面试与考试考察最多的排序，STL 的 `sort` 底层就是快排（兼顾小数组插入排序）。
- **核心思想**：选一个基准（枢轴），把序列partition 成“左边都 ≤ 基准、右边都 ≥ 基准”，再对左右两段递归。
- **过程**：取 `temp = a[low]` 作枢轴；先让 j（high 端）向左找第一个小于枢轴的元素，填到 a[i]；再让 i 向右找第一个大于枢轴的元素，填到 a[j]；交替进行直到 `i == j`，最后 `a[i] = temp`。
- **代码要点**：

```cpp
if(low < high){
    int i = low, j = high, temp = a[low];
    while(i != j){
        while(j > i && a[j] >= temp) --j;   if(i < j){ a[i] = a[j]; ++i; }
        while(i < j && a[i] <  temp) ++i;   if(i < j){ a[j] = a[i]; --j; }
    }
    a[i] = temp;
    quick_sort(a, low, i-1); quick_sort(a, i+1, high);
}
```

- **复杂度**：平均 O(n log n)、最好 O(n log n)、最坏 O(n²)；空间平均 O(log n)（递归栈），最坏 O(n)；**不稳定**。
- **最坏情形**：数据已（正/逆）有序时每次划分极端不均，退化为冒泡级别；对策是随机选枢轴或三数取中。
- 实用技巧：完全逆序的“毒瘤数据”可先 `rand()` 打乱再快排，能显著提速；OJ 上的快排模板题不一定能直接过。

## 8.各种排序算法总结

- **复杂度对照表**（原文整理，已按标准结论校正）：

| 方法 | 平均 | 最好 | 最坏 | 空间 | 稳定性 |
| --- | --- | --- | --- | --- | --- |
| 直接插入 | O(n²) | O(n) | O(n²) | O(1) | 稳定 |
| 希尔排序 | O(n²) | O(n) | O(n²) | O(1) | 不稳定 |
| 直接选择 | O(n²) | O(n²) | O(n²) | O(1) | 不稳定 |
| 堆排序 | O(n log n) | O(n log n) | O(n log n) | O(1) | 不稳定 |
| 冒泡排序 | O(n²) | O(n) | O(n²) | O(1) | 稳定 |
| 快速排序 | O(n log n) | O(n log n) | O(n²) | O(log n) | 不稳定 |
| 归并排序 | O(n log n) | O(n log n) | O(n log n) | O(n) | 稳定 |

- 稳定排序：插入、冒泡、归并（另加基数排序）；其余四个（希尔、选择、堆、快排）均不稳定。
- **适用场景**：
  - 快排：数据越乱越快，已有序时退化；对随机数据综合最优。
  - 插入排序：基本有序、数据量小时最快，稳定。
  - 堆排序：求前 k 大/前 k 小最省力，不必全排。
  - 希尔排序：小数组比快排、堆排更快，大数据不如快排。
  - 归并排序：要求稳定、或数据在链表/外部存储上排序时首选。
- **通用小技巧**：加 flag 提前退出（数据早早有序时可省时间），但若剩余次数很少（如 100 趟只省 5 趟），省的还不如多判断的开销，此时不加更好。
- 选型思路：先看数据规模与初始有序度，再看是否需要稳定、是否只要前 k 个、空间是否紧张；没有十全十美的排序，扬长避短才是对的。
