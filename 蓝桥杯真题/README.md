# 蓝桥杯历年真题（本地归档）

来源: [Dotcpp 蓝桥杯真题](https://www.dotcpp.com/oj/lanqiao/) ｜ 洛谷蓝桥杯题单（省赛/国赛）补充未收录题目 ｜ 抓取时间 2026-11-27

共 757 道不重复题目（Dotcpp 450 道，洛谷补充 307 道），Dotcpp 部分按套累计 691 题次。
目录只按 **年份（届别）** 划分，每年一个文件；不按语言、组别分目录，每道题都标注它在哪些语言/组别里出现过。

## 文件

- 每年目录下一个 `…真题（按题号）.md`：试卷构成、题目一览表（题号 / 标题 / 难度 / 通过率 / 考过的语言组别）、全部题目正文
- `题目总表.md`：757 道题的横向总表
- `题目总表.xlsx`：两个工作表（「题目总表」按题、「题次明细」按套），已冻结表头并带筛选
- `题目总表.csv`：题次维度明细（每行 = 一道题在某套卷子里出现）
- `蓝桥杯真题数据.json`：结构化数据
- `images/`：题干插图

> 通过率：Dotcpp 题取站内历史作答累计百分比；洛谷补充题取洛谷站内通过数/提交数（已注明「洛谷站内口径」），两者口径不同，不宜横向比较。
> 难度：Dotcpp 题沿用站内标注（入门 / 简单 / 中等 / 困难）；洛谷补充题由洛谷 8 档难度换算为 简单 / 中等 / 困难，详情括号内保留洛谷原档。
