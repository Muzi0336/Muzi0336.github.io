# Empty State Vertical Grid

- 真实来源：https://ui.aceternity.com/blocks/empty-states/empty-state-vertical-grid
- 公开预览：https://ui.aceternity.com/live-preview/empty-state-vertical-grid
- 类型：`block`，不是完整模板。
- 许可状态：Aceternity UI Pro / All-Access。公开页面说明该 block 随 All-Access 解锁；未保存受限源码。
- 已保存：`preview.png`，来自官方 live preview 的实际区块截图。

## 用途

点阵背景加三张纵向入口卡，适合课程尚未上线、题库为空、文档占位和 AI 演示无记录时提供下一步选择。可换成赛事、题库、课程三条路径。

## 静态适配

点阵背景、三列卡片和悬停效果均可用 CSS 原生实现；移动端改为单列。减少动效时保留静态卡片即可。改造成本低，三方卡片内容与响应式排布需要重做。
