## 使用说明

- `preview.png` 仅用于设计判断和风格参考。
- 当前共 8 项引用；MotionSites 和 Showreel 条目分别是指公开功能提示词详情与公开案例展示，不是可直接使用的完整网页模板。
- 四个 Aceternity 条目都是 Pro `block`，不是完整模板，也没有保存受限源码。
- 两个 ReactBits 条目是 `component`；其许可禁止独立再分发组件本身，不能标为纯 MIT。
- 正式接入时按本站原生 HTML、CSS 和 JavaScript 重写，并补充移动端、减少动效和静态降级处理。
- 更完整的观察记录见 `.cache/reports/ui-template-candidates.md`，该报告不参与部署。
