# Feature Grid With Minimal Illustrations

- 真实来源：https://ui.aceternity.com/blocks/feature-sections/feature-grid-with-minimal-illustrations
- 公开预览：https://ui.aceternity.com/live-preview/feature-grid-with-minimal-illustrations
- 类型：`block`，不是完整模板。
- 许可状态：Aceternity UI Pro / All-Access。公开页面说明该 block 随 All-Access 解锁；未保存受限源码。
- 已保存：`preview.png`，来自官方 live preview 的实际区块截图。

## 用途

三列极简设备插图配短说明，适合课程占位、文档入口、题库使用说明和三端体验介绍。圆角设备画面可换成直线几何框或 Riso 颗粒插画。

## 静态适配

CSS Grid 加内联或静态图片即可，滚动开合效果可用 CSS 淡入并在减少动效时禁用。移动端单列。静态原生改造成本低，但需自行重绘插图和排版。
