# Gridcore

## 用途

适合本站竞赛通知、资料目录或算法学习页的“功能入口”区域。四等分浅色网格可以承载比赛类别、备考模块、资料入口等功能块，同时在角落加入小图标或编号保持编辑感。

## 观察

- 预览主体是浅灰米白四宫格，分隔线细而克制。
- 文案和几何图标位于格子中部或角落，留白密度适合静态页面扫描。
- 顶部标签为 `editorial`、`3d`、`gradient`，但静态骨架主要依靠编辑式网格而非重动画。
- 右侧相邻项还出现 `Wireframe Forms`、`Diagnostics Panel` 等免费入口，说明该目录混合完整网页和区块级模板。

## 静态适配

将四宫格改为 CSS Grid：`grid-template-columns: repeat(2, minmax(0, 1fr))`，单元用 1px 墨线分隔；图标缩成 24–32px，避免依赖 3D 素材。竞赛页可把四个格子映射为报名、赛程、题库、复盘入口，悬停只做边框显色，不加入连续动画。
