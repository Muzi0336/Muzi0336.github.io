## 用途

三阶段自动轮播加进度线，适合 AI 交互演示步骤、算法训练流程、赛事报名说明或语言题库使用路径。

## 静态适配

用原生按钮、`aria-selected`、CSS Grid 和分层内容可复刻；自动播放可降为手动 Tabs。移动端纵向堆叠，减少动效时取消自动计时与过渡。改造成本中等，主要工作在状态切换和无障碍处理。
