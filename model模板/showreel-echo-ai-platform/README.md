# Echo AI Platform

## 用途

适合本站首页、竞赛专题或题库概览页的大幅通知横幅。可把奶白屏幕面板放在朱红场中，用墨色偏移轮廓形成 Riso/印刷错版层，内容区保持中文标题和两条简短说明。

## 来源

- 真实详情页：https://showreel.design/launch/echo-ai-platform-launch/
- 页面标题：`Echo AI Platform — Echo | Showreel.design`
- 站内检索：使用官方搜索页 `https://showreel.design/?s=geometric`，命中 `Tech & SaaS Geometric/Abstract E Echo AI Platform`。
- 许可状态：公开案例页未声明开源或再分发许可。因此只保留公开预览截图与来源元数据，不保存视频、第三方源码或实现文件。

## 观察

- 首屏以大面积朱红铺底，中央是奶白屏幕，外围有黑色主轮廓和轻微错位的细轮廓。
- 灯具、路牌和人物均为黑色简笔几何，信息密度低，适合竞赛站作为静态专题头图。
- 详情页视频可正常播放，但这里仅采集页面公开可见的预览状态。

## 静态适配

用两层矩形即可：奶白主面板加 2px 墨线边框，外层用 `box-shadow: 5px 5px 0 #b34d37, 8px 8px 0 rgba(47,52,52,.22)` 形成套色偏移。背景保持纯朱红，不复制视频、人物插图或品牌文字；站点可在面板内放真实通知标题与链接。
