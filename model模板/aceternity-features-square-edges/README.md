# Features With Square Edges

- 真实来源：https://ui.aceternity.com/blocks/feature-sections/features-with-square-edges
- 公开预览：https://ui.aceternity.com/live-preview/features-with-square-edges
- 类型：`block`，不是完整模板。
- 许可状态：Aceternity UI Pro / All-Access。公开页面说明该 block 随 All-Access 解锁；未保存受限源码。
- 已保存：`preview.png`，来自官方 live preview 的实际区块截图。

## 用途

三列直角卡片、角标裁切线和黑白编辑排版适合赛事信息、赛道状态、题库入口等需要清晰扫描的区块。可把 AI 笔记示意替换为日期表、统计或题目状态。

## 静态适配

主体可由 CSS Grid、细边框、伪元素角标和普通图片完成；移动端改成单列。滚动显现动画在 `prefers-reduced-motion: reduce` 下关闭即可。静态原生改造成本低，但原 React/Motion 结构和受限源码需要重写。
