## 用途

倾斜图片网格随指针漂移，可改成课程封面、赛事通知、题目分类的几何拼贴。建议使用本站自有图片并降低运动幅度。

## 静态适配

原生可用 CSS Grid、`transform` 和少量 pointer 事件重写；移动端限制位移并在减少动效时完全静止。改造成本中等，图片加载与触屏交互是主要风险。
